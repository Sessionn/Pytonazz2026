## Correzioni dell'audit

| Area | Problema e intervento |
| --- | --- |
| FFmpeg | `4xx,5xx` faceva ritentare anche 403 con lo stesso URL rifiutato. Ora i retry HTTP riguardano 429 e 5xx; restano quelli di rete/TLS. |
| Player | Sorgente PCM controllata: un'uscita FFmpeg non riuscita diventa errore del player anche con versioni Discord che trattano l'EOF come normale. |
| Recupero audio | Un solo recupero della traccia con invalidazione delle cache e nuova risoluzione. I callback di tracce superate non avanzano la coda corrente. Una traccia fallita due volte non resta bloccata in repeat. Ripresa dalla posizione disponibile. |
| Cache web | Le cancellazioni non rinumerano più gli altri ID. Una vecchia scheda non può cancellare un brano diverso perché il suo ID è stato riciclato dalla compattazione. Nessuna migrazione dei dati necessaria; la manutenzione manuale degli ID rimane esplicita. |
| Eventi DJ | Ogni coda SSE conserva un solo snapshot; un client lento non accumula memoria senza limite. |
| Worker web | Massimo quattro stream contemporanei per istanza Flask, lasciando disponibilità nel pool Waitress da otto thread. Gli ulteriori stream ricevono 503; la dashboard ha fallback al polling. La chiusura libera lo slot. |
| SoundCloud | Ripristinata la verifica dei certificati TLS in entrambi i percorsi dei link brevi. |
| Documentazione | README, DOCS, manuale sviluppatori, guida VM e manuale cache aggiornati su pacchetti, branch, tmux e ID stabili. I report precedenti sono marcati come storici. |
| Preview | Ricaricamento dei template abilitato solo nel server di preview, per evitare verifiche su HTML vecchio. |

## Diagnosi del 403

Il server HTTP rifiuta l'URL audio. Il frammento di log non identifica da solo la causa: URL scaduto, restrizione del fornitore, cookie, client di estrazione o cambio di IP/proxy possono produrre questo risultato. La ripetizione dello stesso 403 è invece spiegata dalla precedente configurazione FFmpeg.

Il fix elimina quei tentativi inutili e permette al resolver di richiedere una nuova risorsa. Non garantisce accesso a un contenuto che il fornitore continua a negare. Se il nuovo URL fallisce, verificare yt-dlp, cookie e coerenza del proxy di estrazione/riproduzione; evitare di ritentare indefinitamente o disabilitare TLS.

Riferimento: [protocolli FFmpeg](https://www.ffmpeg.org/ffmpeg-protocols.html), opzione `reconnect_on_http_error`.

## Comandi e funzioni proposti

Proposte, non comandi implementati in questo rilascio. Si possono costruire con software libero e risorse della VM; consumo CPU/disco e limiti dei provider restano da considerare.

| Proposta | Utilità | Impegno e vincoli |
| --- | --- | --- |
| `/scene salva/carica` | Preset personali di EQ, filtri, volume e transizioni, condivisibili nel server | Medio; JSON versionato, permessi DJ e validazione |
| `/mix transizione` | Crossfade ed equal-power tra due brani, con anteprima e annullamento | Alto; richiede due flussi audio e un mixer, non un semplice filtro |
| `/loop segmento` | Ripeti A–B per studio o ascolto, con uscita automatica | Medio; confini precisi, compatibilità seek/provider |
| `/clip crea` | Clip audio o video breve da file caricato, con fade e sottotitoli locali opzionali | Medio/alto; FFmpeg, quote di durata e dimensione, file autorizzati |
| `/soundboard` | Pad personalizzati per effetti e jingle del server | Medio; mix PCM, volume massimo, cooldown e storage limitato |
| `/radio tema` | Coda guidata da artisti/epoca, con motivazione e voto per saltare | Medio; riuso del catalogo e limiti delle API esterne |
| `/sessione salva/riprendi` | Ripristina coda, posizione indicativa e preset dopo riavvio | Alto; persistenza transazionale e rinnovo degli URL temporanei |
| `/sottotitoli` | Trascrizione di un file fornito dall'utente con modello locale | Alto su questa VM; coda lavori CPU, limiti e cancellazione dei file |

### Effetti DJ suggeriti

Priorità: delay sincronizzato al tempo, tremolo con profondità limitata, filtro passa-banda modulato, ducking della musica durante i jingle e crossfade equal-power. Devono entrare nello stesso catalogo/pipeline PCM degli effetti attuali, avere transizioni smussate e reset coerente. Evitare controlli web che mostrano un effetto non applicato realmente all'audio.
